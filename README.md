# Lonely Penguin Game

A fun browser-based arcade game where you help a lonely penguin navigate through the icy Arctic, collect fish, avoid obstacles, and find penguin friends!

## Play the Game

Simply open `index.html` in your web browser to start playing.

## How to Play

- **Space Bar** or **Click/Tap** - Jump
- Avoid icebergs and obstacles
- Collect fish to score points
- Find other penguins to reduce your loneliness meter
- The game speeds up as you progress - how long can you survive?

## Game Features

- Simple, addictive endless runner gameplay
- Cute pixel-art style graphics (drawn with Canvas)
- Progressive difficulty
- High score tracking (saved locally)
- Mobile-friendly touch controls

## Story

In the vast frozen expanse of Antarctica, one little penguin finds itself alone. Help guide this brave penguin across the treacherous ice fields as it searches for friends and collects tasty fish along the way!

## Technical Details

This is a vanilla JavaScript game using HTML5 Canvas - no external dependencies required!

- Pure HTML5, CSS3, and JavaScript
- No frameworks or libraries needed
- Works in all modern browsers
- Responsive design for desktop and mobile

## Development

To run locally, simply open `index.html` in a browser. No build step required!
